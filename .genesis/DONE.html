1 · The Locked Spec (what we are building)

Cognitive job: Given a claim about the world (source, confidence, freshness, scope), record it as an immutable, append-only belief; mechanically detect when a later claim, elapsed time, or a source revocation should make the store trust it less or stop surfacing it as belief at all; and when asked what it currently believes, answer with a closed, exhaustively-matched outcome that can honestly say "I don't know any more, and here is the tombstone proving why" — never silently rank a stale answer highest because it happens to read closer to the question. "Memory that knows it might be wrong": the mechanic is a typed forgetting policy, not a metadata field bolted onto retrieval — see memory-plan.md §2 for the full structural argument against plain RAG.

Inputs: a typed claim (subject, predicate, plain-data value, Provenance, Scope) — never raw, unstructured text handed straight to the store.  →  Outputs: a BeliefAnswer (believed / doubted / disputed / unknown, each carrying the fact that makes it that variant, never a bare ranked list) and, whenever something stops being believed, a Tombstone naming exactly why and, where applicable, exactly what replaced it.

Autonomy level: Fully autonomous for recording a claim, detecting contradiction/decay/ revocation, and answering a query — none of that needs a human in the loop. What is deliberately NOT autonomous: choosing which of two disagreeing, equally-tiered sources to believe. When contradict() (M4) cannot decide mechanically (the disputed outcome, §5.1), the system does not guess — it surfaces both candidates and lets the asker judge, which is itself the correct autonomy level for a claim the store's own rules say it cannot resolve.

Failure tolerance: Fail toward doubt, never toward false confidence. A clock-inconsistent timestamp, an unresolved contradiction, or every known candidate being tombstoned must all push toward doubted/disputed/unknown, never toward a fabricated believed. There is deliberately no LLM anywhere in the contradiction or decay path — lib/contradiction/** and lib/decay/** (M3/M4, unbuilt) are planned to be grep-tested to contain zero LLM-client/network imports, so "you're just asking a model to guess what changed" is falsifiable and false by construction.  |  Trust boundary: a memory's own recorded confidence is never what a query reports — only effectiveConfidence, computed fresh, is (see lib/contracts/effective-confidence.ts).

Filled during Genesis step G0 (Cognitive Design), following the shape used in decision-engine's and shadow-run's own .genesis/DONE.html (this project's infrastructure siblings) — content is project-specific, structure only is borrowed.

2 · Definition of Done (binary gates — checked by the VERIFIER, not the maker)

Dependency direction inward, zero cycles (modular-architecture gate)
npm run typecheck clean AND npm test green
One verify pass by a separate agent/model (L4)
No milestone's freeze boundary touched by a later milestone (freeze-boundary gate — the independent verifier's first job on every milestone)
lib/contradiction/** and lib/decay/** contain zero LLM-client, fetch, or node: network imports (no-story-generator gate, from M3/M4)
A live-query function's parameter type structurally refuses a TombstonedMemory — proven by @ts-expect-error, never a runtime if alone (compile-time-refusal gate, from M1/M5)
Every ForgetReason variant is proven, by a passing test, to actually tombstone something — not merely representable (forgetting-is-proven gate, from M5/M7)
A query over an all-tombstoned corpus returns unknown/all-known-memories-tombstoned — never silently falls back to the highest-confidence dead record (no-silent-fallback gate, from M5)
The fair bag-of-words/cosine baseline (§8) is run as a real, passing test against the exact scenario, not asserted in demo narration (fair-baseline gate, from M7)
The live demo URL runs the §8 address scenario end-to-end from input, driving the real engine (deliverable gate — the brief requires a live demo)
A clean clone plus install plus typecheck plus test passes with no credentials configured (clean-clone gate)

A milestone is DONE only when every applicable box above is checked by the verifier, and never by the building agent marking its own work. There is deliberately no LLM anywhere in the contradiction/decay path, so any generic "LLM schema-validation" gate from a template does not apply here and was dropped.
